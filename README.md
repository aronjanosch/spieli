# Spieli

*Spieli* is German slang for *Spielplatz*, the playground.

Spieli is a desktop library for your [ES-DE](https://es-de.org) collection: browse, search and launch
your games with mouse and keyboard, the way you would in a Steam library. ES-DE stays your
Big Picture mode for the couch. Both read the same data, so nothing has to be set up twice.

Spieli works with any ES-DE setup, whether you configured it by hand or through
RetroDECK, EmuDeck or [Heimspiel](https://github.com/aronjanosch/heimspiel).

## Status
